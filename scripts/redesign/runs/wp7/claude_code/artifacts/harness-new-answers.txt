## Proposed harness: `trading`

**The domain:** daily-bar systematic strategies. Each one is a `signal(bars)` function that returns a position in [-1, 1]. It is scored by a protected evaluator on an out-of-sample window the attempt never sees, after trading costs.

### Standing rules (`instructions/guardrails.md`)
1. **No look-ahead.** A signal at bar t uses only bars at or before t, and the position decided at t earns from t+1. *Source:* the `strategy.py` docstring, the shift in `evaluate.py` (`positions()`), and the brief's first rule.
2. **Keep the contract.** `signal(bars)` returns a Series with one value per bar, within [-1, 1]. *Source:* `evaluate.py` exits with code 2 on any violation.
3. **The out-of-sample bars belong to the evaluator.** Develop on the bars in the workspace and never look for the held-out ones. *Source:* the brief, `generate.py`, and the README's note that they are "not sealed by this example".
4. **No live prices.** Every price comes from the snapshot pinned at setup. *Source:* the brief.
5. **The evaluator is never modified.** *Source:* the brief.
6. **Report a score with its risk line** (max drawdown and turnover), never the Sharpe alone. *Source:* `evaluate.py` prints them before the metric.
7. **Task values are not in the harness.** The window, cost, target and budget come from the task statement.
