# S2: the plugin round, judged

Five dimensions, each scored 1 to 5 from the transcript (docs/plans/semantic-production-tests.md, section 3):

- **proactive**: findings the user did not know, with evidence.
- **clear**: the user's vocabulary, one reason per suggestion, no jargon the persona lacks.
- **not annoying**: no repeated or answerable question, no message over twelve lines plus the brief.
- **engaging**: the user says yes or edits one line rather than re-explaining; the judge predicts the user would return.
- **return on attention**: what the user got (a verified result, a reusable harness, banked lessons, a deployed call) against the minutes of attention it cost.

Score what the conversation shows, not what it promises. A dimension the conversation gives no evidence for scores 1, and the evidence says so.
