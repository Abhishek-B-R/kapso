# WP0: Foundations

2026-10-24. Branch `redesign` (the integration branch itself; WP0 lands
directly on it). Size S, two to three days.

## Scope

What every later package stands on: the integration branch; the CLI split
into one module per verb so packages own disjoint files; the home of the
handles module; the review runner used on every sub-plan and pull
request; the fresh-machine provisioning script for proof runs; the
semantic suite's skeleton with its first fixture, the churn repository
WP1's proof run needs; and the decisions log the owner reads.

**Not in scope.** Any behaviour change (WP1 renames `evolve`; WP0 moves
code without changing what it does). The simulated-user driver and the
judge (WP9, grown from the skill lab when S1 is first run). The docs
navigation (WP10).

## Interface

- `src/kapso/cli/` is a package. `kapso.cli:main` stays the console entry
  point (`pyproject.toml` unchanged). One module per verb:
  `evolve.py` (renamed to `build.py` by WP1), `inbox.py`, `research.py`,
  `learn.py`, `deploy.py`, `index_kg.py`, `bank.py`, `doctor.py`,
  `watch.py`, each exposing `add_parser(subparsers)` and its `cmd_*`
  handler; shared helpers (`_detach`, `_campaign_here`, agent listing) in
  `cli/common.py`; `cli/__init__.py` holds `main()` and re-exports the
  names tests import today, which the test files are then updated to
  import from their new modules (no re-export survives WP0 for a name no
  test needs).
- `src/kapso/handles.py` is reserved for WP1; WP0 creates nothing there.
- `scripts/redesign/review.sh <brief> <out-dir>`: Codex astra at xhigh and
  Claude Code opus-5, read-only, outputs `codex.md` and `claude.md`.
- `scripts/redesign/fresh_machine.sh create|install|run|delete`: a GCP
  machine in the benchmark project, the released package or a wheel from
  the branch installed with `uv`, the two coding-agent CLIs installed,
  logins from the project's secret store, a command run, the machine
  deleted. Nothing from the development checkout is copied.
- `tests/semantic/`: `README.md` (the suite's contract), `fixtures/`
  (`churn-with-evaluator` with `repo/`, `evaluation/evaluate.py` that
  prints the metric on its own line and a fast mode, `data/` generated by
  a script, and the recorded baseline), `personas/` (one card), `report.py`
  (the per-run markdown). Collected by nothing in the ordinary gate.
- `docs/plans/redesign/DECISIONS.md`: the log of decisions not discussed.

## Risks

- Tests that import private CLI helpers break on the move: the grep of
  imports before the split lists them; each is updated in the same commit.
- The fresh machine needs logins: the Codex login on a VM is either a
  copied ChatGPT session (which revokes the development box's when it
  refreshes) or an API key; see the decisions log.
- Cost: an `e2-standard-4` for proof runs is cents per hour; the script
  deletes on exit even when the command fails.
