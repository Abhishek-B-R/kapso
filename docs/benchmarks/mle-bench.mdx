MLE-Bench is a benchmark for evaluating ML engineering agents on Kaggle competitions. Kapso achieved **#1 among open-source systems** on this benchmark.

## Usage

```bash
# List available competitions
PYTHONPATH=. python -m benchmarks.mle.runner --list

# List lite benchmark competitions
PYTHONPATH=. python -m benchmarks.mle.runner --lite

# Solve a competition
PYTHONPATH=. python -m benchmarks.mle.runner -c tabular-playground-series-dec-2021

# With options
PYTHONPATH=. python -m benchmarks.mle.runner \
    -c tabular-playground-series-dec-2021 \
    -i 20 \
    -d codex
```

## CLI options

| Option | Description | Default |
|--------|-------------|---------|
| `-c, --competition` | Competition ID | Required |
| `-i, --iterations` | Max experiment iterations | 20 |
| `-d, --coding-agent` | The host every role without a `cli` of its own runs on | `codex`, the override file's `host` |
| `--no-kg` | Disable knowledge graph | Enabled |
| `--list` | List all competitions | - |
| `--lite` | List lite competitions | - |
| `--list-agents` | List coding agents | - |

## Configuration

`benchmarks/mle/config.yaml` is an override file over the packaged config
(`kapso doctor --show-config --config benchmarks/mle/config.yaml` prints what
a run uses): ideation on Claude Code with the packaged model, implementation
and the judge on the Codex CLI, the inbox off, and the runner's own settings
under `benchmark:`, which the engine never reads.

```yaml
inbox:
  enabled: false
search_strategy:
  params:
    host: codex
    ideation:
      cli: claude_code
      gates: [research, experiment_history, repo_memory]
    implementation:
      gates: [research, repo_memory]
      timeout: 14400
    judge:
      timeout: 900
benchmark:
  fetch_huggingface_models: true
  use_knowledge_graph: true
```

<Note>
The handler supplies the official evaluation: solutions are scored by `mlebench` grading rather than agent-built evaluation.
</Note>

## Stages

The handler automatically adjusts strategy based on budget progress:

| Stage | Budget | Behavior |
|-------|--------|----------|
| **MINI TRAINING** | 0-20% | Sample training data (for datasets >30GB) |
| **FULL TRAINING** | 20-80% | Train on complete dataset |
| **FINAL ENSEMBLING** | 80-100% | Ensemble best models from history |

## Output structure

The agent generates:

```text
experiment_workspace/{uuid}/
├── main.py                    # Entry point
├── output_data_{branch}/
│   ├── final_submission.csv   # Kaggle submission file
│   └── checkpoints/           # Model checkpoints
└── sessions/                  # Experiment branches
```

## Code requirements

Generated code must:
- Support `--debug` flag for fast testing
- Write `final_submission.csv` in the output directory
- Print progress and metrics
- Handle GPU efficiently (batch size, device selection)
- Use early stopping and learning rate scheduling
