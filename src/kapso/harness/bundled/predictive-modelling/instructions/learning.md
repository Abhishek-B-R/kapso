# Learning

Scope every lesson by the data's shape (a flat table, a relational database),
the task type and metric family, the temporal regime, and the size of the
labelled set. A lesson states the practice that measured positive or negative
and the evidence from the attempts (which attempt, which number moved, by
how much against the measured noise), never this task's dataset, columns,
scores or thresholds as facts for the next task.
